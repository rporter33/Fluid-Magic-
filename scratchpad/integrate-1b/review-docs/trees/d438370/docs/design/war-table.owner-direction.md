# Owner direction, 2026-10-21 (binding; quote verbatim in docs)

After reviewing the clickable UI mockup (https://claude.ai/artifact/J9d2JrQYGEhYyfbZyq3uAV,
source: scratchpad/ui-mockup/game-screen-v1.html), the project owner wrote:

> this is great - the UI is fluid - the hover is intuitive and responsive, the alerts row is
> good, each thing to try is good, i would like more detail on the map, while this is mostly an
> art pass, i want to make sure the maps have some impassible terrain that is noticeable, the
> detail view on the lands are great, some art assets to show the growth over time would be
> ideal, based on alignment too!
>
> leaders certainly need portraits
>
> the overall map should be on an rustic wartable in a cozy but natural tavern, nice oak wood

(Typos corrected only: "impassivle" -> "impassible", "ceratinly" -> "certainly", "ting" -> "thing".)

Read as:
1. KEEP: the layered UI (hover, nested tooltips, alerts row, province detail panel) is approved.
2. MORE MAP DETAIL: an art pass on the map itself.
3. IMPASSABLE TERRAIN that is noticeable: a gameplay rule (mapgen + movement + AI pathing), and
   a rendering requirement (it must read at a glance).
4. GROWTH OVER TIME, BASED ON ALIGNMENT: art assets that show provinces developing over the game,
   and that look different depending on alignment (which nation's dominion holds the land, and
   the scales it brings: Order/Turmoil, Growth/Rot, etc., docs/01 section 12).
5. LEADER PORTRAITS: every leader (commander) needs a portrait.
6. THE WAR TABLE: the whole map sits on a rustic war table, in a cozy but natural tavern, with
   nice oak wood.

Earlier binding owner directions that still apply: battles visceral with per-blow detail and
SFX; UI matching similar games with complexity layered under smart menus; flashy magic effects;
Dominions-like pretender options with Age of Wonders 4-level customization; Dominions-like
detailed unit stats (giants to horses) and magic items, immersive but not over-complicated;
colors distinct; the owner has a ChatGPT image-generation plan and can generate raster art on
request (no API key in this environment; owner generates and uploads to art-inbox/).
