# UI and Screens

Desktop first, 1280x720 minimum, 1920x1080 target. Dark UI chrome with the map as the
hero. Panels are DOM over a Pixi canvas. Every number that matters is visible without a
click: population, supply, gold, materials, mana, unrest.

## Screens

1. **Main Menu**: New Game, Continue (autosave), Load, Settings (volume, speed presets),
   About.
2. **New Game**: map size (Small 40 / Medium 60 / Large 80 provinces), seed (random or
   typed), nation pick (card per nation with color symbol and summary), opponents
   (1 to 3 AI, each with a nation or Random; M1 allows duplicates of the two nations),
   AI difficulty (Easy, Normal). Then Pretender Design.
3. **Pretender Design**: see `docs/05-pretender.md`. Three columns: chassis list, pips and
   dominion and scales, live summary card. Preset buttons at the top. Start Game.
4. **Game Screen**: described below.
5. **Battle Replay**: modal over the game, pausable, speed 0.5x to 4x, skip to end.
6. **Victory/Defeat**: result, stats (provinces held, battles won, population under
   rule, mana spent per color), Return to Menu.

## Game screen layout

```
+------------------------------------------------------------------------------+
| TopBar: date | speed controls | gold (+income) | materials(capital) | mana WUBRG | research | menu |
+----------------------+-------------------------------------------+-----------+
|                      |                                           |           |
|  Left dock           |   Map (Pixi)                              | Right     |
|  (province panel     |   pan: drag / WASD, zoom: wheel           | dock      |
|   or commander       |   click province: select                  | (army     |
|   panel, contextual) |   click army marker: select commander(s)  | list of   |
|                      |   right-click province with selection:    | selected  |
|                      |   move there                              | province, |
|                      |                                           | messages) |
+----------------------+-------------------------------------------+-----------+
| Bottom bar: selected commander strip (portrait, squads, orders, script) | ETA |
+------------------------------------------------------------------------------+
```

### Map
- Provinces drawn as filled polygons, terrain color plus a subtle noise texture, 2px
  border, owner color as an inner glow band along the border (color identity of the
  owning nation; independents none).
- Dominion shown as a candle icon stack (1 to 10, grouped by 3) in the province's
  nation color. Toggle overlay modes: Ownership, Dominion, Supply, Unrest, Population,
  Mana springs. Keys F1 to F6.
- Province label: name, population bar under it (log scale), building icons (fort,
  temple, lab), Wellspring icon, spring icons by color.
- Army markers: a shield badge per commander group with troop count; stacked markers
  fan out on hover. Moving armies slide along the edge with an arrow and ETA.
- Hover tooltip: province name, owner, terrain, pop, supply used/available, materials,
  unrest, springs, dominion, defenders (fogged word or exact).

### Province panel (left dock, when a province is selected)
- Header: name, terrain, owner, dominion candles.
- Numbers: population (big), growth per month, gold income, materials, supply, unrest,
  tax rate selector, PD level with a buy button.
- Buildings with a build button (if a commander is present and gold suffices).
- Recruit tab (fort only): unit cards in a grid with costs, batch size input, queue list
  with cancel. Garrison squads list.
- Commanders present: list; click selects.
- Wellspring section when applicable: claim status and progress.

### Commander panel (left dock, when a commander is selected)
- Portrait, name, type, HP, morale, pips as mana symbols, holy, carried mana.
- Orders: buttons for Idle, Pillage, Patrol, Research, Preach, Build, Claim Wellspring,
  Cast Ritual (opens Ritual panel), Make Prophet.
- Squads: list with count, HP%, formation selector, drag to another commander in the
  province (drop targets on the right dock).
- Script: 5 slots with a dropdown each (Cast [spell], Attack, Hold, Retreat).

### Research panel (modal, key R)
- Five columns, one per color, each showing levels 1 to 6 with spell names and a
  progress bar. Click a column header to set the active research color. Shows RP/month
  and months to next level.

### Ritual panel (modal from commander, key C)
- List of castable rituals for the caster, with cost shown as mana symbols, days, and
  description. Target picker highlights valid provinces on the map. Generic payment
  defaults are editable.

### Messages (right dock, bottom)
- Chronological: battles (click to replay), completed recruits, completed rituals,
  research levels, province captured or lost, dominion flipped, starvation warnings,
  Wellspring claimed, enemy army sighted. Each with a jump-to-province button.

### Speed controls
- Buttons: pause, 1, 2, 3, 4. Space pause. Game auto-pauses on: battle involving the
  player, province lost, research level complete (toggleable in settings), victory.

## Battle replay
- Two sides facing each other, three rows per side, squads as blocks of up to 20 sprites
  in a grid (a squad of 50 shows 20 sprites and a count badge). Rounds advance with
  volleys drawn as arcs, melee as lunges, spells as a flash plus a particle burst in the
  color's palette, damage numbers float, routs slide off the edge.
- Side panels list each side's commanders and squads with live counts.

## Accessibility and feel
- All colors also have a symbol (MTG-like mana symbols) so color identity never relies on
  hue alone.
- Tooltips everywhere. Every stat has a one-line explanation.
- Keyboard: Space, 1 to 4, R research, C cast, Esc close, Tab cycle own commanders,
  F1 to F6 overlays, Ctrl+S save.
